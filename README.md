# Semáforo de riesgo estructural en la desigualdad de cuidados

Recurso interactivo de elaboración propia para visualizar cuándo el cuidado funciona como vínculo protector y cuándo puede transformarse en factor de exclusión social.

## Consulta del recurso

[Semáforo interactivo de riesgo estructural](https://carlosarandabcn-80.github.io/Sem-foro-de-riesgo-estructural-en-la-desigualdad-de-cuidados/)

## Objetivo

Facilitar la comprensión de la relación entre cuidados, desigualdad y exclusión estructural mediante tres niveles de lectura: riesgo bajo, riesgo medio y riesgo alto.

## Tecnologías utilizadas

- HTML
- CSS
- JavaScript
